# 문제서재

Vue 3 + TypeScript + Vite로 만드는 선생님용 모의고사 문항 탐색 서비스입니다. 문제 탐색은 로그인 없이 이용하고, 선택적으로 로그인해 개인 서재를 사용할 수 있습니다.

```bash
npm ci
npm run dev
```

검증: `npm test`, `npm run build`. 빌드 결과는 `dist/`에 생성됩니다.

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다. 이후 `main`에 푸시하면 `.github/workflows/deploy-pages.yml`이 테스트와 빌드를 수행하고 배포합니다. **Actions → Deploy to GitHub Pages → Run workflow**로 수동 배포할 수도 있습니다.

배포 대상 주소: https://jaeinlee0502.github.io/gyfl/ (최초 배포 성공 후 접근 가능)

Vite `base`는 프로젝트 Pages 경로 `/gyfl/`로 설정되어 있습니다. 로컬 개발 서버에서도 터미널에 표시되는 `/gyfl/` 경로로 접속합니다. 배포용 빌드는 `npm run preview`로 검토할 수 있습니다. 별도의 배포 토큰은 필요 없으며 워크플로의 기본 `GITHUB_TOKEN`과 Pages/OIDC 권한을 사용합니다. 저장소에서 Actions와 Pages 사용이 허용되어 있어야 합니다.

## 현재 구현

- 국어·수학·영어·한국사·통합사회·통합과학 선택
- 태그 하나와 검색어, 학년, 연도, 시행월의 교집합 검색
- 최신순 / 오래된순 정렬, 정답·해설 펼치기
- 비로그인 브라우저 북마크, 로그인 계정별 북마크, 명시적인 브라우저 목록 가져오기
- 이메일 아이디 로그인·회원가입, 로그인 후 비밀번호 변경
- 관리자 계정 검색·임시 비밀번호 발급·확인 후 일반 계정 삭제 (메일 발송 없음)
- 모바일 반응형 레이아웃, 독립 스크롤 사이드바
- 교육과정과 자료 수록 기준 안내

**8개 문항 모두 자체 제작 예시입니다. EBS 원문이나 실제 모의고사 문항이 아닙니다.** 날짜와 문항 번호는 필터 시연용입니다. 예시는 실제 시험 출제 범위나 난이도를 보증하지 않습니다. 현재 실제 원문 데이터는 0건입니다. 태그는 교사 검토 전 제안입니다.

## 실제 기출 수록 전 필요한 작업

1. 2022 개정 적용 대상인 고1 2025년 이후, 고2 2026년 이후의 3·6·9월 시험을 확인합니다. 현재 시점 이후 자료는 수집하지 않습니다.
2. 시험지·정답·해설 PDF의 이용 및 재배포 조건을 확인합니다. EBS에서 열람 가능하다는 사실만으로 재배포 권한이 있다고 판단하지 않습니다.
3. 적법하게 이용 가능한 PDF를 문항 단위로 잘라 이미지로 저장합니다. 공유 지문·도표·보기·선택지가 잘리지 않도록 사람이 확인하고, 이미지 대체 텍스트와 원본 PDF·페이지·시험명·문항 번호를 기록합니다.
4. 교육과정 및 시험 출제 범위를 검토하고 분야/시대/개념 태그를 검수합니다. 한국사 태그 체계는 사용자와 확정합니다.
5. 예시 레코드와 실제 레코드를 분리하고, 검증된 실제 문항의 별도 데이터 모델·뷰어를 연결합니다. 현재 화면은 텍스트 예시 뷰어이며 실제 이미지 수집·OCR·분류 자동화는 구현되지 않았습니다.

## 계정 기능 연결 상태

Supabase 프로젝트의 읽기 연결은 확인했지만 **현재 관리 토큰의 쓰기 권한이 없어 DB·관리자 서버 설치가 완료되지 않았습니다.** `config/public-project.json`의 `ready`는 `false`이며 로그인 제출은 비활성화되어 있습니다. DB·서버 설치와 실제 검증을 마친 뒤에만 이 값을 변경합니다. 문제 탐색과 기존 브라우저 저장은 계속 제공됩니다. 관리자 화면은 관리자 테이블에서 권한을 확인한 계정에만 표시하고, 서버에서도 매 요청 토큰과 권한을 검증합니다.

설정 순서와 실제 검증 목록은 [계정 기능 연결 안내](docs/auth-setup.md)를 참고하세요. `config/public-project.json`에는 브라우저에서 공개하도록 설계된 프로젝트 URL과 publishable key만 들어 있습니다. GitHub 연결의 Actions Variables 편집 권한이 없어 이 공개 설정 파일을 기본값으로 사용하며, 환경 변수 `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`로 바꿀 수도 있습니다. 관리용 액세스 토큰, service-role/secret 키, DB 비밀번호는 이 파일과 `VITE_` 변수에 넣지 않습니다. 브라우저 설정에 서버 키가 들어오면 빌드를 거절합니다.

이메일은 로그인 아이디로만 사용하고 인증·복구 메일은 발송하지 않습니다. 관리자는 기존 비밀번호를 조회하는 대신 새 임시 비밀번호를 발급하고 선생님에게 직접 전달합니다. 임시 비밀번호는 응답 화면에만 일시 표시하고 저장하지 않습니다. 선생님은 로그인 후 비밀번호를 변경할 수 있습니다. 일반 계정 삭제는 대상 아이디 재입력 후에만 실행하며, 관리자 계정은 이 화면에서 초기화·삭제할 수 없습니다. 문항 관리는 이 관리자 화면의 범위가 아닙니다.
