# 문제서재

Vue 3 + TypeScript + Vite로 만드는 로그인 없는 선생님용 모의고사 문항 탐색 서비스의 첫 프로토타입입니다.

```bash
npm ci
npm run dev
```

검증: `npm test`, `npm run build`. 빌드 결과는 `dist/`에 생성됩니다.

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다. 이후 `main`에 푸시하면 `.github/workflows/deploy-pages.yml`이 테스트와 빌드를 수행하고 배포합니다. **Actions → Deploy to GitHub Pages → Run workflow**로 수동 배포할 수도 있습니다.

배포 대상 주소: https://jaeinlee0502.github.io/gyfl/ (최초 배포 성공 후 접근 가능)

Vite `base`는 프로젝트 Pages 경로 `/gyfl/`로 설정되어 있습니다. 로컬 개발 서버에서도 터미널에 표시되는 `/gyfl/` 경로로 접속합니다. 배포용 빌드는 `npm run preview`로 검토할 수 있습니다. 별도의 배포 토큰은 필요 없으며 워크플로의 기본 `GITHUB_TOKEN`과 Pages/OIDC 권한을 사용합니다. 저장소에서 Actions와 Pages 사용이 허용되어 있어야 합니다.

## 현재 구현

- 국어·수학·영어·한국사·통합사회·통합과학 선택
- 태그 하나와 검색어, 학년, 연도, 시행월의 교집합 검색
- 최신순 / 오래된순 정렬, 정답·해설 펼치기
- 브라우저 localStorage 북마크, 모바일 반응형 레이아웃
- 교육과정과 자료 수록 기준 안내

**8개 문항 모두 자체 제작 예시입니다. EBS 원문이나 실제 모의고사 문항이 아닙니다.** 날짜와 문항 번호는 필터 시연용입니다. 예시는 실제 시험 출제 범위나 난이도를 보증하지 않습니다. 현재 실제 원문 데이터는 0건입니다. 태그는 교사 검토 전 제안입니다.

## 실제 기출 수록 전 필요한 작업

1. 2022 개정 적용 대상인 고1 2025년 이후, 고2 2026년 이후의 3·6·9월 시험을 확인합니다. 현재 시점 이후 자료는 수집하지 않습니다.
2. 시험지·정답·해설 PDF의 이용 및 재배포 조건을 확인합니다. EBS에서 열람 가능하다는 사실만으로 재배포 권한이 있다고 판단하지 않습니다.
3. 적법하게 이용 가능한 PDF를 문항 단위로 잘라 이미지로 저장합니다. 공유 지문·도표·보기·선택지가 잘리지 않도록 사람이 확인하고, 이미지 대체 텍스트와 원본 PDF·페이지·시험명·문항 번호를 기록합니다.
4. 교육과정 및 시험 출제 범위를 검토하고 분야/시대/개념 태그를 검수합니다. 한국사 태그 체계는 사용자와 확정합니다.
5. 예시 레코드와 실제 레코드를 분리하고, 검증된 실제 문항의 별도 데이터 모델·뷰어를 연결합니다. 현재 화면은 텍스트 예시 뷰어이며 실제 이미지 수집·OCR·분류 자동화는 구현되지 않았습니다.

공개 열람만 필요한 초기 버전은 정적 JSON과 이미지 저장소로 충분합니다. 편집자가 늘거나 웹에서 문항을 등록·검수해야 하면 Supabase(Postgres + Storage)와 **관리자 전용 인증**을 추가할 수 있습니다. 일반 열람자에게는 로그인이 필요 없습니다. 비밀키나 service-role 키를 프론트엔드에 두지 않습니다.

원문 후보: https://www.ebsi.co.kr/ebs/xip/xipa/retrieveSCVMainInfo.ebs?irecord=202609022&targetCd=D200&cookieGradeVal=high2

개발 당시 참고 사이트와 EBS 페이지는 네트워크 정책의 403 응답으로 확인하지 못했습니다. 디자인은 요청한 기능을 바탕으로 독립적으로 작성했습니다.
