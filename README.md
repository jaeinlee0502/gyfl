# 문제서재

고양외고 교직원이 사용하는 학교 전용 모의고사 문항 서재입니다. Vue 3 + TypeScript + Vite와 Supabase Auth / Postgres / 비공개 Storage를 사용합니다.

사이트: https://jaeinlee0502.github.io/gyfl/

## 이용 방식

- 첫 화면에서 로그인하거나 가입을 신청합니다. 새 계정과 기존 일반 계정은 관리자가 교직원 여부를 확인하고 승인해야 입장할 수 있습니다.
- 기존 관리자는 바로 입장합니다. 상단 **계정 관리**에서 승인 대기 목록 조회, 이용 승인·승인 취소, 계정 검색, 임시 비밀번호 발급, 확인 후 일반 계정 삭제를 지원합니다.
- 계정별로 문제를 저장하고 **저장한 문제만** 필터로 확인합니다. 로그아웃하면 불러온 문항과 저장 목록을 화면에서 제거합니다.
- 이메일 형식의 문자열을 로그인 아이디로 사용합니다. 인증·복구 메일은 보내지 않으며, 교직원 여부는 관리자가 직접 확인합니다. 비밀번호를 잊으면 관리자에게 문의합니다.

## 수록 자료

2025년 고1 3월 전국연합학력평가 한국사 20문항을 문항별 이미지와 시대·개념 태그로 수록합니다. 해설 본문은 표시하지 않고 각 문항에서 해당 EBSi 공식 회차로 연결합니다. 이 회차의 실제 출제 범위 기록은 보존하며, 학년·연도만으로 고교 2022 개정 문항이라고 인증하지 않습니다.

국어·수학·영어·한국사·통합사회·통합과학 메뉴, 태그·원문 내용 검색, 학년·연도·시행월 필터를 제공합니다. 아직 자료가 없는 과목은 빈 상태를 안내합니다. 기존 자체 제작 예시는 개발용 데이터이며 운영 목록에 섞어 표시하지 않습니다.

실제 문항의 이미지·OCR 원문·분류 데이터는 이 공개 Git 저장소나 GitHub Pages 빌드에 포함하지 않습니다. `exam_questions`의 RLS와 비공개 `school-questions` 버킷이 승인된 사용자와 관리자만 읽도록 제한합니다. 이미지는 캐시를 재사용하지 않는 사용자 인증 다운로드 후 브라우저 Blob URL로 표시하며 로그아웃·승인 취소 확인 시 URL을 해제합니다. 사용자가 이미 열람한 자료를 복사하거나 저장하는 것까지 막는 기능은 아닙니다.

관리자는 상단 **문제 등록**에서 문제지 PDF 업로드 → 시험 정보·문항·공통 지문 인식 → 이미지·태그 검수 → 초안 저장 또는 등록을 진행합니다. 해설지 업로드는 필수가 아닙니다. 공통 지문은 한 번 저장하여 문항에 연결하고, 검색·저장·태그 숫자는 문항별로 유지합니다. 영어 듣기는 원문의 안내에서 확인한 번호 범위로 제외하며, 수학은 선택형·단답형을 구별합니다. 기본 태그·제목은 문제 키워드에 따른 규칙으로 추천합니다. 관리자가 **AI 일괄 추천 / AI 제목 제안**을 선택하면 서버에 연결된 Gemini 또는 OpenAI로 본문·공통 지문과 선택 첨부한 해설 텍스트를 보내 구체적인 제목을 제안합니다. AI 결과는 확인 후 적용하며 원래 제목을 자동으로 덮어쓰지 않습니다. 스캔 PDF나 다른 편집 형식은 영역을 직접 추가하거나 수정해 확인합니다. PDF는 최대 20MB·40쪽, 등록은 한 번에 100문항까지 지원합니다. [업로드·검수 안내](docs/pdf-imports.md)를 참고하세요. 로그인 제한은 원문에 대한 이용허락을 대신하지 않으며, 자료별 이용 조건은 별도로 관리합니다.

## 개발과 검증

```bash
npm ci
npm run dev
npm test
npm run build
```

Vite 경로는 `/gyfl/`입니다. 계정 설정이 없으면 문제 탐색을 열지 않고 준비 화면을 표시합니다. 테스트는 운영 Supabase에 연결하지 않습니다. 빌드 결과는 `dist/`에 생성됩니다.

## 서버 구성

마이그레이션을 순서대로 적용하고 관리자 함수를 배포합니다.

- `supabase/migrations/202610250001_accounts_and_bookmarks.sql`
- `supabase/migrations/202610250002_school_library.sql`
- `supabase/migrations/202610250003_exam_imports.sql`
- `supabase/migrations/202610260001_shared_passages.sql`
- `supabase/migrations/202610260002_import_registration_and_deletion.sql`
- `supabase/functions/account-admin/`
- `supabase/functions/exam-admin/`

두 번째 마이그레이션은 일반 계정을 자동 승인하지 않습니다. 세 번째는 관리자 전용 업로드 초안·비공개 PDF 버킷·검수 완료 등록 트랜잭션을 추가하며, 네 번째는 공통 지문·영역별 비공개 이미지·문항 연결을 같은 등록 트랜잭션으로 검증합니다. 다섯 번째는 태그 없는 검수 문항의 등록과 관리자 확인 후 등록 자료 삭제·재업로드를 지원합니다. 삭제는 해당 업로드의 문항·지문·저장 기록만 정리하고, 파일 정리 실패 시 재시도할 수 있습니다. 관리자는 `account_admins`, 승인된 교직원은 `school_members`에서 서버가 확인합니다. 사용자 메타데이터나 브라우저의 표시 값으로 접근 권한을 부여하지 않습니다. 승인 변경은 서버 전용 RPC로 처리하고 별도 감사 기록을 남깁니다.

서버 설치·계정 운영 절차는 [계정 연결 안내](docs/auth-setup.md), 교직원 승인 절차는 [학교 서재 운영](docs/school-library.md)을 참고하세요.

`config/public-project.json`에는 브라우저용 프로젝트 URL과 publishable key만 포함합니다. `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`로 덮어쓸 수 있습니다. 서비스 키·관리 토큰·DB 비밀번호는 공개 설정이나 `VITE_` 변수에 넣지 않습니다.

## 배포

GitHub Pages의 배포 원본은 GitHub Actions입니다. `main` 푸시 시 `.github/workflows/deploy-pages.yml`이 테스트·빌드 후 사이트를 배포합니다. 문제 원문은 Supabase의 비공개 저장소에서 별도로 제공됩니다. 웹 화면 배포만으로 서버의 마이그레이션이나 함수가 갱신되지는 않습니다.
