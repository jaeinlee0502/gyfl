# PDF 업로드·검수

관리자 계정으로 로그인한 뒤 상단 **문제 등록**을 누릅니다. 일반 교직원 계정에는 등록 메뉴가 표시되지 않습니다.

1. **문제지 PDF**를 선택하고 **PDF 분석·업로드**를 누릅니다. 최대 20MB·40쪽까지 지원합니다. 해설지 파일은 필수가 아닙니다. 문제지의 지문·조건·그림과 질문을 기준으로 태그를 추천하며, 해설은 EBS 링크로 확인합니다.
2. 머리말에서 찾은 **과목·학년·연도·시행월**을 확인합니다. 인식하지 못한 정보는 직접 선택합니다. EBS 회차 링크를 알면 출처·해설 링크에 붙이고, 모르면 학년별 기출문제 목록 링크를 사용할 수 있습니다.
3. 문항 이미지의 지문·그림·보기·선택지가 모두 보이는지 확인합니다. 잘린 부분은 **영역 조정**에서 페이지를 고르고 드래그하거나 위치(%)를 입력한 뒤 **영역 적용·미리보기 갱신**을 누릅니다.
4. 여러 문항이 공유하는 지문은 **공통 지문**에서 한 번 검수하고, 각 문항의 **공통 지문 연결**을 확인합니다. 두 단이나 다음 쪽에 이어지는 지문은 여러 영역으로 순서대로 보관합니다. 자동으로 찾지 못한 지문은 직접 추가할 수 있습니다. 문항 자체가 여러 영역에 걸친 경우에는 문항의 영역을 추가합니다. **영역 앞으로 이동·뒤로 이동**으로 읽는 순서를 조정합니다. 자동으로 찾지 못한 문항은 **문항 직접 추가**, 불필요한 문항은 **문항 제외**를 사용합니다.
5. 제목·문항 번호·배점·태그를 확인합니다. 태그는 쉼표 또는 `#`로 구분해 입력하거나 추천 버튼으로 추가합니다. 기본 태그·제목 추천은 단어에 따른 규칙 방식입니다. 구체적인 주제 중심의 제목을 원하면 **AI 일괄 추천** 또는 문항별 **AI 제목 제안**을 사용합니다.
6. 공통 지문과 문항별 검수 확인을 체크합니다. 모두 살펴본 뒤 화면 맨 아래의 **전체 검수 확인**을 누르면 문항과 공통 지문을 한 번에 체크할 수 있습니다. 같은 버튼의 **전체 확인 해제**로 되돌릴 수 있습니다. 이후 제목·태그·영역·지문 연결 등을 바꾸면 관련 확인이 해제됩니다. 연결할 문항이 없는 지문은 연결하거나 제외합니다. 태그는 선택 사항이므로 자동 추천이 없거나 비워 둔 문항도 등록할 수 있습니다. 등록을 막는 입력 오류가 있으면 하단과 해당 문항에 번호·이유를 표시합니다. 모든 지문·문항 검수와 시험 정보 입력이 끝나면 **확인한 문제 등록**을 누릅니다.

제목은 질문의 첫 문장을 복사하는 대신 문제의 개념·단원, 공통 지문의 주제·작품, 문항에서 묻는 내용을 기준으로 추천합니다. 예를 들어 수학은 제곱근의 계산이나 삼각형의 성질, 국어는 작품과 서술 방식 또는 지문의 개념 비교처럼 표시합니다. 이미지의 문제 원문은 그대로 보존합니다. 제목도 키워드·유형 규칙에 따른 초안이므로 실제 문항에 맞는지 확인하고 직접 수정할 수 있습니다.

기존에 저장한 초안은 자동으로 제목을 덮어쓰지 않습니다. 각 문항의 **제목 추천**에서 제안을 보고 적용하거나 **제목 일괄 추천**에서 바꿀 항목만 골라 적용합니다. 일괄 추천은 빈 제목·깨진 제목·‘의 핵심 개념’으로 끝나는 포괄적인 제목을 우선 선택하며, 직접 수정한 제목은 선택하지 않으면 유지됩니다. 제목을 바꾼 문항은 다시 검수 확인하고 **초안 저장**을 누릅니다. 파일을 다시 올릴 필요는 없습니다.

## AI 제목 추천과 선택 해설지

**4. 문항·태그 검수**의 **AI 일괄 추천**은 문항을 5개씩 나누어 요청합니다. 문항별로는 **AI 제목 제안**을 누릅니다. 추천 전후 제목을 비교하고 바꿀 제목만 적용하세요. 숨겨진 인물·국가·제도나 정답을 제목으로 알려주지 않고, 원문에서 확인되는 소재·개념을 사용하도록 요청합니다. AI가 틀릴 수 있으므로 최종 제목과 문항 이미지를 확인합니다. API 실패 시 기존 제목을 유지하고 원인을 안내하며, 규칙 결과를 AI 결과로 대체해 표시하지 않습니다.

**해설지 PDF (선택)**에는 같은 과목·학년·회차의 해설지를 첨부할 수 있습니다. 텍스트가 있는 20MB·40쪽 이하, 추출 텍스트 60,000자 이하의 파일을 지원합니다. 확인 가능한 시험 정보가 다르면 첨부를 거절합니다. 회차가 머리말에서 확인되지 않는 경우 관리자가 직접 맞는 파일인지 확인해야 합니다. AI에는 같은 문항 번호의 해설만 참고하도록 요청합니다. 해설지는 현재 창에서 제목 추천에만 사용하며 초안·Storage에 보관하지 않습니다. 다시 검수 창을 열면 필요한 경우 다시 첨부합니다.

Supabase 프로젝트의 **Edge Functions → Secrets**에서 `OPENAI_API_KEY`를 설정하고 `exam-admin` 함수를 배포합니다. 기본 모델은 `gpt-4.1-mini`이며 `OPENAI_TITLE_MODEL`로 변경할 수 있습니다. 키를 `VITE_` 변수·공개 설정·소스에 넣지 않습니다. 인증된 관리자만 AI 요청을 사용할 수 있고, 요청당 최대 10문항·기존 512KB 요청 제한을 적용합니다. OpenAI 요청의 `store`는 `false`입니다. 사용 비용과 요청 한도는 연결한 OpenAI API 프로젝트를 따릅니다.

## 과목별 추출 기준

- **국어**: `[1~3]` 같은 실제 공통 지문을 문항과 분리하여 연결합니다. 지문 앞의 제목·(가)(나)와 주석, 다음 단·쪽에 이어지는 내용을 확인합니다.
- **영어**: 머리말에서 듣기 번호 범위를 확인하면 해당 문항을 제외하고 원래 번호를 유지합니다. 예를 들어 제공된 2025년 고1 3월은 듣기 1~17번을 빼고 독해 18~45번 28문항을 남깁니다. 같은 쪽에 듣기·독해가 함께 있어도 독해를 남깁니다. 실제 공통 지문(41~42, 43~45)과 공통 문제 지시(빈칸·순서·삽입)를 구분합니다. 공통 지시만 쓰는 문제는 각 지문을 독립 문항으로 유지합니다. 듣기 범위를 확인하지 못한 파일에서는 임의로 1~17번을 삭제하지 않고 안내하므로 직접 제외할 범위를 확인합니다.
- **수학**: 선택형·단답형을 구별합니다. 단답형에 선택지가 없는 것은 정상입니다. 수식과 도형은 원본 이미지로 보존하며 바깥의 과도한 빈 여백을 줄입니다. 분수·지수·도형 이름이 모두 보이는지 확인합니다.
- **사회·과학**: `탐구 영역(사회)`와 `탐구 영역(과학)` 표기를 사이트의 통합사회·통합과학 메뉴에 연결합니다. 한 문항의 지도·그래프·실험·복수 그림·범례·보기·선택지를 함께 보존합니다. 파일에 실제 공통 지문이 있으면 같은 연결 방식으로 검수합니다.

서재에서는 공통 지문을 한 번 표시하고 연결 문항을 나열합니다. 태그·검색·저장은 개별 문항 단위입니다. 일부 문항만 검색하거나 저장해도 필요한 공통 지문이 함께 보이며, 같은 지문의 나머지 문항을 펼쳐볼 수 있습니다. 태그 옆 숫자는 묶음 수가 아닌 조건에 맞는 문항 수입니다. 공통 지문 이미지도 PC·모바일에서 눌러 확대할 수 있습니다.

중간에 **초안 저장**을 누르면 창을 닫았다가 **저장된 업로드 → 이어서 검수**로 계속할 수 있습니다. 시험 정보가 일부 비어 있어도 초안 저장이 가능합니다. 미등록 초안은 원본 PDF와 함께 삭제할 수 있습니다.

같은 과목·학년·연월·문항 번호가 이미 등록된 경우 전체 등록을 거절합니다. 기존 문항을 자동으로 덮어쓰거나 일부만 등록하지 않습니다. 현재 수록된 2025년 고1 3월 한국사를 다시 올려 등록하면 이 중복 안내가 표시됩니다. **등록 완료 자료도 삭제 후 다시 올릴 수 있습니다.** 저장된 업로드 목록에서 **등록 자료 삭제**를 누르면 파일명과 삭제 영향을 안내합니다. 최종 확인하면 해당 파일의 원본 PDF·초안·등록 문항·공통 지문·이미지와 사용자들의 해당 문항 저장 기록이 함께 삭제되며 되돌릴 수 없습니다. 다른 파일의 자료는 유지됩니다. 삭제 후 수정한 PDF를 다시 분석·검수하여 등록하세요. 파일 삭제가 중간에 실패하면 **삭제 재시도**로 남은 파일을 정리할 수 있습니다. 삭제 중인 자료는 검수나 등록을 다시 진행할 수 없습니다.

스캔 PDF는 텍스트나 문항 경계를 인식하지 못할 수 있습니다. 이 경우 이미지로 페이지를 보며 영역과 태그를 직접 지정합니다. 여러 단·쪽으로 이어지는 긴 지문도 반드시 미리보기를 확인합니다. 기본 등록에는 별도 API 키가 필요하지 않습니다. AI 제목 추천은 서버의 OpenAI 연결이 필요하며, 버튼을 누른 경우에만 추출한 본문·공통 지문·선택 해설 텍스트를 전송합니다. 스캔 이미지의 별도 OCR이나 그림 분석은 하지 않습니다.

업로드 원본과 미등록 초안·이미지는 관리자 전용 비공개 저장소에 보관합니다. 검수 후 등록된 문항만 승인된 교직원 서재에 표시합니다. PDF·문항 원문을 Git 저장소에 넣지 않습니다.

서버 구성은 `202610250003_exam_imports.sql`, `202610260001_shared_passages.sql`과 `exam-admin` 함수입니다. 지문 이미지도 비공개 저장소에 보관하며 등록된 지문만 승인된 교직원이 읽을 수 있습니다. 변경 시 DB 마이그레이션과 Edge Function을 먼저 반영하고 프론트엔드를 배포합니다. PDF 워커·문자 매핑·폰트·이미지 디코더는 사이트와 같은 호스트에서 제공합니다.
