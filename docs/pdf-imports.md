# PDF 업로드·검수

관리자 계정으로 로그인한 뒤 상단 **문제 등록**을 누릅니다. 일반 교직원 계정에는 등록 메뉴가 표시되지 않습니다.

1. **문제지 PDF**를 선택하고 **PDF 분석·업로드**를 누릅니다. 최대 20MB·40쪽까지 지원합니다. 해설지 파일은 필수가 아닙니다. 문제지의 지문·조건·그림과 질문을 기준으로 태그를 추천하며, 해설은 EBS 링크로 확인합니다.
2. 머리말에서 찾은 **과목·학년·연도·시행월**을 확인합니다. 인식하지 못한 정보는 직접 선택합니다. 빠지거나 잘못된 항목은 입력란과 등록 버튼 옆에 구체적으로 표시합니다. 기존 문항이 있는 초안을 다시 열 때는 누락된 과목·학년·연월만 원본 PDF에서 복원하며, 직접 입력한 값과 검수한 제목·문항 영역은 유지합니다. EBS 회차 링크를 알면 출처·해설 링크에 붙이고, 모르면 학년별 기출문제 목록 링크를 사용할 수 있습니다.
3. 문항 이미지의 지문·그림·보기·선택지가 모두 보이는지 확인합니다. PDF의 실제 문항 정렬 위치로 좌우 단을 구분합니다. 오른쪽 단이 페이지 중앙보다 왼쪽에서 시작하는 편집 형식도 같은 기준으로 처리합니다. 잘린 부분은 **영역 조정**에서 페이지를 고르고 드래그하거나 위치(%)를 입력한 뒤 **영역 적용·미리보기 갱신**을 누릅니다.
4. 여러 문항이 공유하는 지문은 **공통 지문**에서 한 번 검수하고, 각 문항의 **공통 지문 연결**을 확인합니다. 두 단이나 다음 쪽에 이어지는 지문은 여러 영역으로 순서대로 보관합니다. 자동으로 찾지 못한 지문은 직접 추가할 수 있습니다. 문항 자체가 여러 영역에 걸친 경우에는 문항의 영역을 추가합니다. **영역 앞으로 이동·뒤로 이동**으로 읽는 순서를 조정합니다. 자동으로 찾지 못한 문항은 **문항 직접 추가**, 불필요한 문항은 **문항 제외**를 사용합니다.
5. AI가 기본값으로 채운 제목·태그와 문항 번호·배점을 확인합니다. 태그는 쉼표 또는 `#`로 구분해 입력하거나 추천 버튼으로 추가합니다. 신규 업로드·빈 초안 복구·원본 재분석에서는 문항을 5개씩 나누어 제목과 태그를 자동 추천합니다. 과목이 미확정이면 과목 선택 후 **AI 제목·태그 추천**을 사용합니다. 저장된 초안의 수동 수정은 자동으로 덮어쓰지 않습니다. 다시 추천할 때는 적용 전 제목·태그와 분류 근거를 비교합니다.
6. 공통 지문과 문항별 검수 확인을 체크합니다. 모두 살펴본 뒤 화면 맨 아래의 **전체 검수 확인**을 누르면 문항과 공통 지문을 한 번에 체크할 수 있습니다. 같은 버튼의 **전체 확인 해제**로 되돌릴 수 있습니다. 이후 제목·태그·영역·지문 연결 등을 바꾸면 관련 확인이 해제됩니다. 연결할 문항이 없는 지문은 연결하거나 제외합니다. 태그는 선택 사항이므로 자동 추천이 없거나 비워 둔 문항도 등록할 수 있습니다. 등록을 막는 입력 오류가 있으면 하단과 해당 문항에 번호·이유를 표시합니다. 모든 지문·문항 검수와 시험 정보 입력이 끝나면 **확인한 문제 등록**을 누릅니다.

제목은 질문의 첫 문장을 복사하는 대신 문제의 개념·단원, 공통 지문의 주제·작품, 문항에서 묻는 내용을 기준으로 추천합니다. 예를 들어 수학은 제곱근의 계산이나 삼각형의 성질, 국어는 작품과 서술 방식 또는 지문의 개념 비교처럼 표시합니다. 이미지의 문제 원문은 그대로 보존합니다. 제목과 태그는 AI가 제안한 초안이므로 실제 문항에 맞는지 확인하고 직접 수정할 수 있습니다. API를 쓰지 않는 기존 **제목 추천 / 제목 일괄 추천**도 남아 있습니다.

기존에 저장한 초안은 자동으로 제목을 덮어쓰지 않습니다. 각 문항의 **제목 추천**에서 제안을 보고 적용하거나 **제목 일괄 추천**에서 바꿀 항목만 골라 적용합니다. 일괄 추천은 빈 제목·깨진 제목·‘의 핵심 개념’으로 끝나는 포괄적인 제목을 우선 선택하며, 직접 수정한 제목은 선택하지 않으면 유지됩니다. 제목을 바꾼 문항은 다시 검수 확인하고 **초안 저장**을 누릅니다. 파일을 다시 올릴 필요는 없습니다.

## AI 제목·태그 기본값과 시대 분류

한국사는 검색에 쓰는 **선사·고대 / 중세 / 근세 / 근대 / 일제강점기 / 현대사** 중 중심 시대 하나와 정치사·경제사·사회사·문화사를 구별합니다. 현대사는 1945년 광복 이후, 일제강점기는 1910년 병합부터 광복 이전, 근대는 1876년 개항부터 병합 이전으로 요청합니다. 사회탐구도 기존 윤리·정치·법·경제·지리 등의 검색 태그 안에서 분류합니다.

모든 AI 태그에는 본문·공통 지문·같은 번호 해설의 인용 근거를 요구합니다. 서버는 원문에 존재하는지 대조하며, 본문의 객관식 선택지에만 있는 인용은 근거로 인정하지 않습니다. 한국사에서 시대가 여러 개 반환되거나 근거가 없으면 시대 태그를 비우고 **AI 분류 참고**에 검수할 내용을 표시합니다. AI의 의미 판단 자체는 틀릴 수 있으므로 등록 전에 근거와 시대를 확인합니다. 메뉴의 시대 필터는 저장한 태그와 정확히 일치하는 문항만 보여 줍니다.

신규 업로드의 AI 결과는 화면의 기본값에 바로 적용되며 검수 확인은 해제된 상태입니다. **초안 저장**으로 보관합니다. 한도·연결 오류가 나면 완료한 묶음은 유지하고 미완료 문항의 태그는 비운 채 안내합니다. 성공한 AI 분류인 것처럼 규칙 태그를 넣지 않습니다. **AI 제목·태그 추천** 또는 문항별 **이 문항 AI 제목·태그 추천**으로 재시도할 수 있습니다. 기존 초안에서는 추천 전후를 확인하고 **추천 제목·태그 적용 / 선택한 제목·태그 적용**으로 바꿀 항목만 적용합니다. 이미 저장된 초안을 열기만 해서는 AI를 다시 호출하지 않습니다.

## 제목만 추천하거나 선택 해설지 참고하기

**4. 문항·태그 검수**의 **AI 일괄 추천**은 문항을 5개씩 나누어 요청합니다. 문항별로는 **AI 제목 제안**을 누릅니다. 추천 전후 제목을 비교하고 바꿀 제목만 적용하세요. 숨겨진 인물·국가·제도나 정답을 제목으로 알려주지 않고, 원문에서 확인되는 소재·개념을 사용하도록 요청합니다. AI가 틀릴 수 있으므로 최종 제목과 문항 이미지를 확인합니다. API 실패 시 기존 제목을 유지하고 원인을 안내하며, 규칙 결과를 AI 결과로 대체해 표시하지 않습니다.

**해설지 PDF (선택)**에는 같은 과목·학년·회차의 해설지를 첨부할 수 있습니다. 텍스트가 있는 20MB·40쪽 이하, 추출 텍스트 60,000자 이하의 파일을 지원합니다. 확인 가능한 시험 정보가 다르면 첨부를 거절합니다. 회차가 머리말에서 확인되지 않는 경우 관리자가 직접 맞는 파일인지 확인해야 합니다. AI에는 같은 문항 번호의 해설만 참고하도록 요청합니다. 해설지는 현재 창에서 제목·태그 추천에만 사용하며 초안·Storage에 해설 원문을 보관하지 않습니다. AI 분류 검수 안내에는 해당 해설을 요약한 근거가 포함될 수 있습니다. 다시 검수 창을 열면 필요한 경우 다시 첨부합니다.

Supabase 프로젝트의 **Edge Functions → Secrets**에서 다음과 같이 서비스를 선택하고 `exam-admin` 함수를 배포합니다.

| 서비스 | `AI_TITLE_PROVIDER` | 키 | 기본 모델 | 모델 변경(선택) |
| --- | --- | --- | --- | --- |
| Gemini | `gemini` | `GEMINI_API_KEY` | `gemini-3.5-flash-lite` | `GEMINI_TITLE_MODEL` |
| OpenAI | `openai` | `OPENAI_API_KEY` | `gpt-4.1-mini` | `OPENAI_TITLE_MODEL` |

서비스를 지정하지 않으면 기존 OpenAI 설정을 사용합니다. 선택한 서비스의 키만 사용하며, 키 누락·한도 초과·연결 실패 시 다른 서비스로 자동 전환하지 않습니다. 키를 `VITE_` 변수·공개 설정·소스에 넣지 않습니다. 인증된 관리자만 AI 요청을 사용할 수 있고, 요청당 최대 10문항·기존 512KB 요청 제한을 적용합니다. OpenAI 요청의 `store`는 `false`입니다. Gemini는 Google의 공식 OpenAI 호환 API를 사용합니다. 두 서비스 모두 문항 식별자·제목 길이·잘린 응답 등을 검증한 뒤 추천 결과만 반환합니다. 이전 자동 태그의 오분류와 오답 선택지보다 본문·공통 지문·해설의 근거를 우선하도록 요청합니다.

채팅 구독과 API 사용료는 별도입니다. Gemini의 기본 모델에는 [무료 구간](https://ai.google.dev/gemini-api/docs/pricing)이 있지만 실제 무료 사용 가능 여부·요청 한도는 연결된 Google AI Studio 프로젝트에서 확인해야 합니다. 결제가 활성화된 프로젝트에는 유료 요금이 적용될 수 있습니다. Google 요금표에 따르면 무료 구간의 입력·출력은 제품 개선에 사용될 수 있으며, 유료 구간의 데이터 조건과 다릅니다. 서비스 선택 전에 해당 프로젝트의 이용 조건을 확인하세요. Gemini의 일일 한도와 일시적인 분당 요청 제한, 인증 오류는 별도로 안내하며 기존 제목을 유지합니다.

## 잘못된 문항·지문 영역을 다시 분석하기

이전 분석에서 문항이 누락되거나 공통 지문에 다른 문항이 섞였다면 **2. 시험 정보 확인 → 원본 다시 분석**을 사용할 수 있습니다. 영역 편집 중에는 먼저 적용하거나 취소하고 초안을 저장한 뒤 새로고침해 최신 분석 코드를 불러오세요. 저장된 업로드에서 **이어서 검수**한 다음 재분석합니다. PDF를 다시 업로드하지 않습니다.

재분석 확인 화면에서 교체할 범위를 안내합니다. 실행하면 현재 문항·제목·태그·영역·공통 지문 연결을 새로 생성하고 검수 확인을 해제합니다. 직접 입력한 시험 정보는 유지합니다. 새 결과는 **초안 저장** 또는 등록 전까지 서버 초안을 덮어쓰지 않습니다. 확인 화면에서 취소하면 현재 화면의 기존 문항을 유지합니다.

## 과목별 추출 기준

- **국어**: `[1~3]` 같은 실제 공통 지문을 문항과 분리하여 연결합니다. 지문 앞의 제목·(가)(나)와 주석, 다음 단·쪽에 이어지는 내용을 확인합니다.
- **영어**: 머리말에서 듣기 번호 범위를 확인하면 해당 문항을 제외하고 원래 번호를 유지합니다. 예를 들어 제공된 2025년 고1 3월은 듣기 1~17번을 빼고 독해 18~45번 28문항을 남깁니다. 같은 쪽에 듣기·독해가 함께 있어도 독해를 남깁니다. 실제 공통 지문(41~42, 43~45)과 공통 문제 지시(빈칸·순서·삽입)를 구분합니다. 공통 지시만 쓰는 문제는 각 지문을 독립 문항으로 유지합니다. 듣기 범위를 확인하지 못한 파일에서는 임의로 1~17번을 삭제하지 않고 안내하므로 직접 제외할 범위를 확인합니다.
- **수학**: 선택형·단답형을 구별합니다. 단답형에 선택지가 없는 것은 정상입니다. 반복되는 하단 쪽번호와 테두리를 문제 영역에서 제외한 뒤 바깥의 과도한 빈 여백을 줄입니다. 수식과 도형의 얇은 선은 내용으로 보존합니다. 기존 초안도 새로고침 후 **이어서 검수**하면 같은 방식으로 미리보기를 갱신하며, 저장된 제목·태그·직접 조정한 좌표를 유지합니다. 등록 완료된 이미지는 자동으로 바꾸지 않습니다. 분수·지수·도형 이름이 모두 보이는지 확인합니다.
- **사회·과학**: `탐구 영역(사회)`와 `탐구 영역(과학)` 표기를 사이트의 통합사회·통합과학 메뉴에 연결합니다. 한 문항의 지도·그래프·실험·복수 그림·범례·보기·선택지를 함께 보존합니다. 파일에 실제 공통 지문이 있으면 같은 연결 방식으로 검수합니다.

서재에서는 공통 지문을 한 번 표시하고 연결 문항을 나열합니다. 태그·검색·저장은 개별 문항 단위입니다. 일부 문항만 검색하거나 저장해도 필요한 공통 지문이 함께 보이며, 같은 지문의 나머지 문항을 펼쳐볼 수 있습니다. 태그 옆 숫자는 묶음 수가 아닌 조건에 맞는 문항 수입니다. 공통 지문 이미지도 PC·모바일에서 눌러 확대할 수 있습니다.

중간에 **초안 저장**을 누르면 창을 닫았다가 **저장된 업로드 → 이어서 검수**로 계속할 수 있습니다. 시험 정보가 일부 비어 있어도 초안 저장이 가능합니다. 미등록 초안은 원본 PDF와 함께 삭제할 수 있습니다.

같은 과목·학년·연월·문항 번호가 이미 등록된 경우 전체 등록을 거절합니다. 기존 문항을 자동으로 덮어쓰거나 일부만 등록하지 않습니다. 현재 수록된 2025년 고1 3월 한국사를 다시 올려 등록하면 이 중복 안내가 표시됩니다. **등록 완료 자료도 삭제 후 다시 올릴 수 있습니다.** 저장된 업로드 목록에서 **등록 자료 삭제**를 누르면 파일명과 삭제 영향을 안내합니다. 최종 확인하면 해당 파일의 원본 PDF·초안·등록 문항·공통 지문·이미지와 사용자들의 해당 문항 저장 기록이 함께 삭제되며 되돌릴 수 없습니다. 다른 파일의 자료는 유지됩니다. 삭제 후 수정한 PDF를 다시 분석·검수하여 등록하세요. 파일 삭제가 중간에 실패하면 **삭제 재시도**로 남은 파일을 정리할 수 있습니다. 삭제 중인 자료는 검수나 등록을 다시 진행할 수 없습니다.

스캔 PDF는 텍스트나 문항 경계를 인식하지 못할 수 있습니다. 이 경우 이미지로 페이지를 보며 영역과 태그를 직접 지정합니다. 여러 단·쪽으로 이어지는 긴 지문도 반드시 미리보기를 확인합니다. 영역 검수·수동 입력·등록에는 별도 API 키가 필요하지 않습니다. 새 PDF의 AI 제목·태그 기본값에는 서버의 Gemini 또는 OpenAI 연결이 필요하며 분석 시 추출한 본문·공통 지문을 전송합니다. 선택 해설 원문은 연결한 상태에서 다시 추천할 때 함께 참고합니다. 스캔 이미지의 별도 OCR이나 그림 분석은 하지 않습니다.

업로드 원본과 미등록 초안·이미지는 관리자 전용 비공개 저장소에 보관합니다. 검수 후 등록된 문항만 승인된 교직원 서재에 표시합니다. PDF·문항 원문을 Git 저장소에 넣지 않습니다.
