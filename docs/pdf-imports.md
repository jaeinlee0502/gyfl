# PDF 업로드·검수

관리자 계정으로 로그인한 뒤 상단 **문제 등록**을 누릅니다. 일반 교직원 계정에는 등록 메뉴가 표시되지 않습니다.

1. **문제지 PDF**를 선택하고 **PDF 분석·업로드**를 누릅니다. 최대 20MB·40쪽까지 지원합니다.
2. 머리말에서 찾은 **과목·학년·연도·시행월**을 확인합니다. 인식하지 못한 정보는 직접 선택합니다. EBS 회차 링크를 알면 출처·해설 링크에 붙이고, 모르면 학년별 기출문제 목록 링크를 사용할 수 있습니다.
3. 문항 이미지의 지문·그림·보기·선택지가 모두 보이는지 확인합니다. 잘린 부분은 **영역 조정**에서 페이지를 고르고 드래그하거나 위치(%)를 입력한 뒤 **영역 적용·미리보기 갱신**을 누릅니다.
4. 여러 문항이 공유하는 지문이나 다음 페이지에 이어지는 부분은 **공통 지문 영역 추가**로 붙입니다. 여러 영역은 선택한 순서대로 하나의 문항 이미지로 이어 붙습니다. **영역 앞으로 이동·뒤로 이동**으로 공통 지문을 문제 앞에 배치할 수 있습니다. 자동으로 찾지 못한 문항은 **문항 직접 추가**, 불필요한 문항은 **문항 제외**를 사용합니다.
5. 제목·문항 번호·배점·태그를 확인합니다. 태그는 쉼표 또는 `#`로 구분해 입력하거나 추천 버튼으로 추가합니다. 현재 추천은 단어에 따른 규칙 방식이며 AI 자동 분류가 아닙니다.
6. 문항별 **이미지와 태그를 확인했어요**를 체크합니다. 이후 제목·태그·영역 등을 바꾸면 해당 확인이 해제됩니다. 모든 문항 검수와 시험 정보 입력이 끝나면 **확인한 문제 등록**을 누릅니다.

중간에 **초안 저장**을 누르면 창을 닫았다가 **저장된 업로드 → 이어서 검수**로 계속할 수 있습니다. 시험 정보가 일부 비어 있어도 초안 저장이 가능합니다. 미등록 초안은 원본 PDF와 함께 삭제할 수 있습니다.

같은 과목·학년·연월·문항 번호가 이미 등록된 경우 전체 등록을 거절합니다. 기존 문항을 자동으로 덮어쓰거나 일부만 등록하지 않습니다. 현재 수록된 2025년 고1 3월 한국사를 다시 올려 등록하면 이 중복 안내가 표시됩니다. 등록 완료 자료는 이 화면에서 수정·삭제하지 않습니다.

스캔 PDF는 텍스트나 문항 경계를 인식하지 못할 수 있습니다. 이 경우 이미지로 페이지를 보며 영역과 태그를 직접 지정합니다. 여러 단·쪽으로 이어지는 긴 지문도 반드시 미리보기를 확인합니다. 현재 별도 OCR·AI API 키는 필요하지 않으며, 외부 AI로 PDF를 보내지 않습니다.

업로드 원본과 미등록 초안·이미지는 관리자 전용 비공개 저장소에 보관합니다. 검수 후 등록된 문항만 승인된 교직원 서재에 표시합니다. PDF·문항 원문을 Git 저장소에 넣지 않습니다.

서버 구성은 `202610250003_exam_imports.sql`과 `exam-admin` 함수입니다. 변경 시 DB 마이그레이션과 Edge Function을 먼저 반영하고 프론트엔드를 배포합니다. PDF 워커·문자 매핑·폰트·이미지 디코더는 사이트와 같은 호스트에서 제공합니다.
