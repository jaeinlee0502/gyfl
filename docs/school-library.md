# 학교 서재 운영

사이트: https://jaeinlee0502.github.io/gyfl/

## 처음 입장

1. 운영자는 기존 관리자 아이디로 로그인합니다.
2. 다른 선생님은 로그인 창에서 회원가입합니다. 이름은 관리자가 교직원임을 확인할 수 있게 입력합니다.
3. 관리자가 상단 **계정 관리**에서 신청자의 이름·이메일 아이디를 확인하고 **이용 승인**을 누릅니다.
4. 선생님은 승인 대기 화면의 **승인 상태 다시 확인**을 눌러 입장합니다.

회원가입만으로는 문제를 볼 수 없습니다. 이메일 인증을 보내지 않으므로 이메일 주소만 보고 학교 구성원으로 판단하지 말고 실제 교직원인지 확인합니다. 기존 일반 계정도 최초 한 번 승인이 필요합니다.

## 승인 취소와 계정 지원

**승인 취소**는 이용 권한만 회수하며 계정과 저장한 문제를 유지합니다. 재승인할 수 있습니다. 새로 권한을 확인하는 문항 조회·이미지 다운로드는 제한됩니다. 열린 화면은 다시 권한을 확인할 때 로그인 입구로 돌아가며, 이미 열람하거나 저장한 자료를 원격으로 회수할 수는 없습니다.

**비밀번호 초기화**는 새 임시 비밀번호를 한 번 보여줍니다. 요청자 본인인지 확인한 뒤 직접 전달하고, 해당 선생님이 로그인 후 비밀번호를 변경하도록 안내합니다. 메일은 발송하지 않습니다.

**계정 삭제**는 확인란에 대상 아이디를 입력한 뒤 실행하며 계정과 저장 목록을 지웁니다. 자기 계정이나 다른 관리자 계정은 이 화면에서 초기화·승인 취소·삭제할 수 없습니다.

## 현재 문항

한국사 2025년 고1 3월 20문항이 등록되어 있습니다. 시대와 개념 태그로 검색하고 책갈피로 저장합니다. 정답·해설은 문항 아래의 EBS 링크에서 확인합니다. 모바일과 좁은 화면에서는 문제 이미지가 가로 너비를 채웁니다. PC·모바일 모두 문제 이미지를 누르면 큰 화면에서 확대·축소하며 볼 수 있습니다. 다른 과목은 자료 등록 후 이용할 수 있습니다.

문제 원문을 공개 GitHub 저장소의 `public/` 폴더나 소스에 추가하지 않습니다. 현재 이미지는 Supabase 비공개 버킷에 있으며 승인된 계정으로 인증한 다운로드만 허용됩니다. 관리자는 상단 **문제 등록**에서 문제지 PDF를 올리고 검수할 수 있습니다. 자세한 순서는 [PDF 업로드·검수](pdf-imports.md)를 참고하세요.

국어·영어의 공통 지문은 한 번 표시하고 관련 문제들을 개별 문항으로 검색·저장합니다. 검색이나 저장 목록에 일부 문제만 있어도 연결된 지문을 함께 볼 수 있습니다. 영어 듣기는 원문 안내에서 확인한 번호 범위로 제외합니다. 해설지 업로드는 필수가 아니며, 태그 추천이 애매한 경우 승인된 교직원이 문제 아래의 **태그 편집**에서 원문과 EBS 해설을 참고하여 수정할 수 있습니다. 변경한 태그는 모든 교직원에게 공유됩니다. 자세한 절차는 [공유 태그 안내](shared-tags.md)를 참고하세요.
