# 교직원 공유 태그 편집

학교 이용 승인을 받은 교직원과 관리자는 등록된 문제 아래의 **태그 편집**을 사용할 수 있습니다. 편집창에서 기존 태그를 선택·해제하거나 쉼표·`#`·줄바꿈으로 구분해 새 태그를 입력한 뒤 **태그 저장**을 누릅니다. 태그는 최대 20개, 각각 60자이며 모두 비우면 해당 문항의 태그를 지웁니다.

수정한 태그는 모든 교직원이 공유합니다. 저장한 화면에서는 문제의 태그·검색·태그별 문제 수가 즉시 갱신됩니다. 한국사 추천 키워드는 지정한 9개만 표시하고, 추가 태그는 문항의 태그 버튼과 검색창에서 찾을 수 있습니다. 다른 과목에서는 새 태그도 추천 키워드에 나타납니다. 다른 선생님은 문제 목록을 새로 불러오면 변경한 태그를 확인할 수 있습니다. 제목·문제 원문·시험 정보는 이 기능으로 변경하지 않습니다. 태그 편집에는 AI API를 호출하지 않습니다.

동시에 다른 선생님이 같은 문제의 태그를 저장하면 오래된 편집 내용을 덮어쓰지 않습니다. 안내를 확인하고 **최신 태그 불러오기**로 현재 값을 읽은 뒤 다시 수정합니다. 최신 태그를 불러오면 편집창의 입력도 현재 값으로 바뀝니다.

서버에는 `202610270001_shared_question_tags.sql`을 적용합니다. `update_exam_question_tags` RPC는 실제 로그인 사용자의 `auth.uid()`와 `has_school_access()`를 확인하며, 가입 후 승인 대기 중이거나 승인이 취소된 계정은 사용할 수 없습니다. 인증 클라이언트에 문항 테이블의 직접 쓰기 권한을 추가하지 않습니다. 변경 전후 태그와 작업자 ID는 서버 전용 `exam_question_tag_audit`에 같은 트랜잭션으로 기록합니다. 문제를 삭제하면 해당 문제의 변경 기록도 정리합니다.
