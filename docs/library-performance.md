# 목록과 이미지 불러오기

접속 시 모든 과목의 원문 이미지를 먼저 받지 않습니다. `loadQuestions(subject)`가 학교 이용 승인을 확인한 다음 선택한 과목의 문항 정보와 필요한 공통 지문 정보를 읽어 목록·검색·태그 개수를 준비합니다. 화면은 일부 결과부터 표시하며 **문제 더 보기**로 계속 볼 수 있습니다. 공통 지문과 연결 문항은 같은 묶음을 유지합니다. 검색과 태그 개수는 아직 화면에 펼치지 않은 문항도 포함합니다.

`PrivateQuestionImage`는 화면 가까이 나타날 때 `loadImage(path)`를 요청합니다. 인증 다운로드는 최대 4개씩 진행하고, 같은 파일에 대한 중복 요청과 이미 불러온 파일은 현재 과목을 보는 동안 메모리에서 재사용합니다. 한 이미지가 실패하면 해당 위치에서 **이미지 다시 불러오기**를 제공합니다. 나머지 문항과 검색은 계속 사용할 수 있습니다.

이미지는 기존 비공개 저장소와 교직원 승인 정책을 사용하며 공개 URL을 만들지 않습니다. 로그아웃·승인 상실·과목 변경·목록 새로 불러오기 때 다운로드를 취소하고 Blob URL과 메모리 캐시를 해제합니다. 이전 계정·목록에서 늦게 도착한 응답은 표시하지 않습니다.

한국사의 **추천 키워드**는 선사·고대, 중세, 근대, 일제강점기, 현대사, 정치사, 경제사, 사회사, 문화사 9개로 고정합니다. 추천 목록의 변경은 저장된 태그나 AI 분류 기준을 바꾸지 않습니다. 예를 들어 기존 근세 태그는 문항에 그대로 남으며 문항의 태그 버튼이나 검색창으로 찾을 수 있습니다. 다른 과목은 기본 키워드와 교직원이 추가한 태그를 함께 표시합니다.
